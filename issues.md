# Smart Clinic Management System - User Stories

## Doctor User Stories
- As a Doctor, I want to securely log into the system so that I can view my schedule.
- As a Doctor, I want to view my daily patient appointments so that I know who I am treating today.
- As a Doctor, I want to add prescriptions for patients so that their medication history is documented.
- As a Doctor, I want to update my available times so that patients can book appointments with me.

## Patient User Stories
- As a Patient, I want to securely log in so that I can access my medical information.
- As a Patient, I want to search for doctors by name or specialty so that I can find a suitable provider.
- As a Patient, I want to view a doctor's availability so that I can book an appointment.
- As a Patient, I want to book an appointment with a doctor so that I can get medical consultation.
- As a Patient, I want to view my past and upcoming appointments so that I can keep track of my healthcare.
- As a Patient, I want to view my prescriptions so that I know what medications I need to take.

## Admin User Stories
- As an Admin, I want to log into the system securely so that I can manage clinic operations.
- As an Admin, I want to add new doctors to the system so that they can start taking appointments.
- As an Admin, I want to view reports on the number of appointments per doctor so that I can monitor clinic efficiency.
- As an Admin, I want to manage patient records so that the system data remains accurate.
